# AGENTS.md

## Projeto

- Projeto Java.
- Mod de Minecraft desenvolvido com Fabric.
- Versão do Minecraft: 26.3.
- O mod adiciona novos Olhos do Ender.
- Cada olho deve utilizar itens encontrados em diferentes biomas.
- O objetivo é incentivar a exploração antes de o jogador finalizar o jogo.

## Orientação do assistente

- Apenas instrua o usuário sobre como realizar alterações.
- Não altere arquivos ou código diretamente.
- Explique de forma simples, curta e objetiva.
- Indique quais arquivos, classes e métodos o usuário deve modificar.
- Forneça exemplos de código quando forem úteis.
- Antes de sugerir mudanças, investigue a estrutura e os padrões existentes.
- Não suponha a versão do Minecraft, Fabric Loader, Fabric API ou mappings; verifique os arquivos do projeto.
- Preserve a compatibilidade com Fabric e com a versão usada pelo projeto.
- Avise claramente quando alguma informação for assumida ou inferida.
